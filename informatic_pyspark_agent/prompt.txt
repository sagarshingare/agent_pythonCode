## 1. XML INPUT HANDLING

- Parse:
  - Mapping
  - Source / Target
  - Transformations
  - Maplets
  - Expressions

---

## 2. XML → JSON CONVERSION

- Convert XML → structured JSON
- Preserve hierarchy:
  - mapping
  - transformation
  - connectors
  - maplets

---

## 3. CANONICAL MODEL

- Normalize JSON into canonical format:
  - mapping_name
  - sources
  - targets
  - steps[]
  - dependencies
  - maplet references

- Must be deterministic (NO LLM)

---

## 4. MULTI-AGENT ARCHITECTURE

---

### 🔷 PlannerAgent (NEW - CRITICAL)

- Orchestrates entire flow
- Decides:
  - which agents to call
  - execution order
- Generates execution plan like:

step1: parse XML  
step2: build canonical  
step3: generate code  
step4: validate  
step5: optimize  

---

### 🔷 SpecAgent
- XML → JSON → Canonical

---

### 🔷 CodeGenAgent
- Convert canonical → PySpark
- Support:
  - Filter
  - Expression
  - Aggregation
  - Join
  - Maplet expansion

---

### 🔷 ValidationAgent
- Generate:
  - row count checks
  - EXCEPT queries
  - hash comparisons

---

### 🔷 OptimizationAgent
- Add:
  - repartition
  - cache
  - broadcast joins

---

### 🔷 OrchestrationAgent
- Generate Airflow DAG dynamically

---

### 🔷 DocumentationAgent (NEW)

Generate documentation from XML:

- Mapping overview
- Source → Target lineage
- Transformation logic explanation
- Column-level mapping
- Save as Markdown in output/docs/
